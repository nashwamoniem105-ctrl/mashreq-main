# إعداد Firebase لمشروع Mashreq

لقد تم تحويل التطبيق ليعمل باستخدام **Firebase Firestore** بدلاً من SQL التقليدية، مما يجعله متوافقاً مع الاستضافة على **Netlify** أو أي منصة أخرى.

## الخطوات المطلوبة للتشغيل:

1. **متغيرات البيئة (Environment Variables)**:
   يجب إضافة متغير بيئة جديد باسم `FIREBASE_SERVICE_ACCOUNT` في لوحة تحكم Netlify (أو منصة الاستضافة).
   - **القيمة**: يجب أن تكون محتوى ملف الـ JSON الخاص بـ Service Account الذي تم توليده.

2. **قاعدة البيانات**:
   تم إنشاء مشروع Firebase باسم `mashreq-db-final-v3`. تأكد من تفعيل **Firestore Database** في وضع **Test Mode** أو إعداد القواعد (Rules) لتسمح بالقراءة والكتابة.

3. **التطوير المحلي**:
   إذا أردت التشغيل محلياً، ضع ملف `firebase-key.json` في المجلد الرئيسي للمشروع، وسيقوم التطبيق بالتعرف عليه تلقائياً.
